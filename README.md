# Pizzería Los Álamos — web demo

Menú online con carrito y pedido por WhatsApp. HTML + CSS + JS vanilla, sin build: se abre con doble clic en `index.html`.
Todo el contenido (menú, precios, horarios, contacto, colores) está en `data.js`.

## Pendiente de confirmar con el cliente (buscar `PENDIENTE CLIENTE` en `data.js`)
- Dirección, localidad y mapa de Google (la sección "Cómo llegar" queda con botón a WhatsApp hasta tenerlos)
- Número de WhatsApp (se usó el 11 3340 4927 que aparece en sus fotos)
- Costo y zona de envío, pedido mínimo y formas de pago (Cuenta DNI incluida como supuesto)
- Precio de las canastas (no figura en el menú)
- Vigencia de las "Más promos" (salen en un menú viejo)
- Fotos de pizzas y de helados
- Reseñas reales de Google y URL final de la web

## Publicar
Hosting estático (GitHub Pages / Cloudflare Pages). Al publicar, completar `seo.url` en `data.js` y `og:url` en `index.html`.

Web hecha por Vigolo Web Studio.
